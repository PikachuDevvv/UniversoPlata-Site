# Enciclopédia do Universo Plata

Site estático feito em HTML, CSS e JavaScript.

## Como abrir
1. Extraia o ZIP.
2. Abra `index.html` no navegador.

Também pode publicar a pasta inteira no GitHub Pages, Netlify ou Render (Static Site).

## Assets
Os quatro arquivos PNG fornecidos foram mantidos em `assets/`:
- `logo-universo-plata.png`
- `fundo-universoplata-novo.png`
- `overlay-universo-plata.png`
- `plata.png`

## Camadas visuais
- Fundo: fixo na janela, não acompanha a rolagem.
- Logo: fixada no topo.
- Overlay: camada fixa no topo de todos os elementos, sem bloquear cliques.

## Conteúdo
O perfil de Plata usa os detalhes já conhecidos. As categorias sem informações confirmadas estão preparadas como páginas em construção, para não inventar fatos do universo.
